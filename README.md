# Notification service
Service exposing REST endpoint for receiving request from tracking-service to publish notifications to clients.
Currently just logging calls.

## Technologies
Java 21, Spring Boot 3, Open API 

## CI, CD, Cloud technologies
AWS ECS, AWS ECR, AWS Parameter Store,AWS CloudWatch, AWS Managed Prometheus, AWS Managed Grafana, Git Actions, 
Git Packages, Docker, Confluent Cloud Kafka
